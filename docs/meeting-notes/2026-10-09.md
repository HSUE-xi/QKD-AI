# 2026-10-09 會議紀錄

## 專題名稱

量子通訊金鑰傳輸 AI 識別竊聽系統

## 分組

### A 組：通訊組

成員：

- 林子桀
- 許程景
- 周冠辰

工作：

1. 建立虛擬量子通道，包含發送端 Alice 和接收端 Bob。
2. 模擬金鑰透過粒子傳遞的過程。
3. 模擬真實傳輸中的雜訊與干擾，例如光纖老化、光子翻轉。
4. 建立竊聽端 Eve，模擬駭客造成的人為干擾。
5. 將測試資料輸出成 CSV，提供給 B 組訓練。

### B 組：機器學習組

成員：

- 王端宏
- 何名綸，兼任 PM 協助

工作：

1. 使用 A 組提供的 CSV 訓練 AI。
2. 使用決策樹演算法，將資料整理成特徵 `X` 與標籤 `y`。
3. 印出混淆矩陣，確認 AI 不會把駭客竊聽誤認為一般雜訊。
4. 調整決策樹參數與深度，避免 overfitting。
5. 將訓練好的模型打包成 `.pkl` 檔案，交給 C 組。

### C 組：PM / 系統整合

成員：

- 范語芸

工作：

1. 系統架設與維護環境。
2. 追蹤各組進度。
3. 必要時進行協助與人員調度。
