# QKD-AI 專案總覽

## 專案目標

本專題要建立一個「量子通訊金鑰傳輸 AI 識別竊聽系統」。第一版以 BB84 量子金鑰分配為核心，模擬 Alice 和 Bob 的鏈路資料，辨別正常狀態、通道劣化與攔截重送。

第一版重點不是做出最完整的量子物理模擬，而是先完成可交接、可訓練、可展示的 MVP。

## 分組

### A 組：通訊組

成員：林子桀、許程景、周冠辰

工作：

1. 建立虛擬量子通道，包含 Alice 和 Bob。
2. 模擬 BB84 傳輸流程。
3. 加入簡化通道擾動與光子遺失，後續再擴充真實設備效應。
4. 加入 Eve 攔截重送攻擊。
5. 輸出固定格式 CSV 給 B 組。

### B 組：機器學習組

成員：王端宏、何名綸

工作：

1. 讀取 A 組產生的 CSV。
2. 將資料切成特徵 `X` 與標籤 `y`。
3. 使用決策樹訓練分類模型。
4. 印出混淆矩陣，觀察 Eve 與自然雜訊的誤判和漏判。
5. 將模型輸出成 `.pkl`。

### C 組：PM / 系統整合

成員：范語芸

工作：

1. 維護專案環境。
2. 追蹤各組進度。
3. 協助整合 A 組 CSV 與 B 組模型。
4. 整理會議紀錄與交付項目。

## 第一版範圍

CSV v1 約定五種成因標籤，分階段產生：

- 10/18 基本版：`normal`、`depolarizing_noise`、`intercept_resend`。
- 10/25 診斷版：再加入 `fiber_aging`、`polarization_drift`，並將部分攔截納入 `intercept_resend`。

詳細定義只維護在 [CSV 格式規格](csv-format.md)，避免不同文件產生兩套欄位說明。

整合成功標準：

- A 組能產生至少數百到數千筆 CSV。
- CSV 欄位符合 [CSV 格式規格](csv-format.md)。
- B 組能讀 CSV、訓練決策樹、印出混淆矩陣。
- B 組能輸出 `models/decision_tree_qkd.pkl`，並將結果和只看 QBER 的基準比較。

## 後續擴充

第一版跑通後，可以逐步加入：

- 經老師確認後的弱相干光與誘餌態、PNS 和偵測器情境。
- Random Forest、SVM、神經網路等模型。
- 簡單前端或展示介面。
