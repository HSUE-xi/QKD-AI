## 第一階段物理假設

- 每次發送一個理想偏振單光子；Alice 與 Bob 獨立選 Z/X 基底，只有基底相同且 Bob 有點擊的位元進入篩選。從篩選位元隨機抽公開測試子集估計錯誤率，不使用其餘位元作特徵。
- `basic` 使用各類共通的隨機損耗範圍。`depolarizing_noise` 以設定機率把 Bob 的結果改為隨機 bit，僅代表明確定義的簡化雜訊，不等同完整光纖模型。
- `diagnostic` 的距離為 5–25 km，基準衰減係數為 `0.2 dB/km`；抵達率 `eta = 10^(-alpha * L / 10)`。老化使 `alpha` 在一個 run 內逐步上升；此版偵測器理想，純損耗只降低點擊數，不增加理想 QBER。
- 偏振漂移以 H/V 態之間的 Z 軸相位差簡化，X 基底同基底測量的翻轉機率為 `sin²(theta/2)`，Z 基底不受此效應影響。這不是所有實際偏振漂移的通用模型。
- Eve 以隨機基底攔截並重送部分或全部光子。診斷模式的大部分攻擊只攔截 8%–24%，少部分為完整攔截；各情境仍有低程度背景雜訊。去極化、部分攔截與漂移的總 QBER 範圍故意重疊，不為提高準確率而刪掉難例。

## 驗證與交接

1. 以固定種子的至少 100,000 次發送情境驗證理想統計：基底匹配率約 50%、完整攔截 QBER 約 25%、部分攔截約 `f/4`；短區塊則允許有限樣本波動。
2. 驗證 20 km、`0.2 dB/km` 的理想抵達率約 0.398；關閉雜訊與攻擊後，任何距離的純損耗 QBER 應為 0。漂移情境要檢查 Z/X 錯誤率差異。
3. 每次產生資料後檢查 CSV 欄名、計數關係、`sample_id` 對應及同種子重現。`data/qkd_truth.csv` 僅供 A 組驗證；交 B 組的是 `data/qkd_dataset.csv`。
4. B 組按**完整 run**切分訓練與測試，不能讓同一 run 的正常基準與故障段分到兩側；時間趨勢僅由當下與先前的可觀測區塊推得。

A 組驗收的是物理假設清楚、數據可重現、沒有答案洩漏且 B 組可依規格讀取。分類準確率不構成 QKD 安全性證明；是否比只看 QBER 更有用，由 B 組在相同測試條件下評估。
